# Security Policy

## Supported Versions

Only the latest release version is supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.x.x   | Yes       |
| < 1.0.0 | No        |

## Reporting a Vulnerability

We take the security of the SNIST Helpdesk seriously. If you find any security vulnerabilities, please do **NOT** open a public issue.

Please report vulnerabilities by emailing **security.helpdesk@sreenidhi.edu.in**.

Provide a detailed description of the vulnerability, including:
- A Proof of Concept (PoC) or step-by-step instructions to reproduce the issue.
- Impact details.
- Environment details.

We will acknowledge receipt of your report within 48 hours and work with you to patch the issue before public disclosure.
